# Linear Regression

## Overview
This project demonstrates Linear Regression, a supervised machine learning algorithm used to predict continuous numerical values.

## What I Learned
- Understanding the basic idea of Linear Regression
- Training a regression model using Python
- Making predictions using the trained model
- Evaluating model performance

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Project File
- `linear_regression.ipynb` — notebook containing the code, training process, and results.

## How to Run
Open the notebook in Google Colab and run the cells sequentially.
